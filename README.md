# MAYDON

Realistic mobile football where you control **one** footballer (REMATCH-style), with AI or friends on the other slots.
Godot 4.7, Mobile renderer, Android-first.

## Layout
| path | what |
|---|---|
| `game/` | Godot project (open this folder in Godot) |
| `game/src/sim` | pure-data match simulation (ball physics, footballers, rules) — runs headless/host |
| `game/src/ai` | team + player AI, formations |
| `game/src/input` | input state + human controller (assists) |
| `game/src/view` | match scene, pitch/venue builders, camera, characters, shaders |
| `game/src/ui` | menus, HUD, touch controls, results, tutorial |
| `game/src/core` | Game (settings/profile/save), Sfx, League/progression |
| `game/src/net` | LAN multiplayer (UDP discovery + ENet) |
| `game/locale/strings.csv` | UI strings uz/ru/en (generated by `tools_py/gen_strings.py`) |
| `blender/` | Blender scripts for characters (`chars/`) and the mocap library (`anim/`) |
| `tools_py/` | Pillow generators (ads, icon, numbers, strings) |
| `raw/` | downloaded source assets (not shipped) + `ATTRIBUTION.md` |
| `docs/` | roadmap, store listing, privacy policy |

## Commands
- `./compile.sh` — compile every script/scene, list errors
- `./check.sh` — 1 headless AI match (sim/AI sanity)
- `godot --headless --path game res://tools/bench.tscn -- <per_side> <matches> <seconds>` — AI vs AI stats
- `godot --headless --path game res://tools/human_test.tscn -- 5 3 240` — scripted human through the real control path
- `./shot.sh <arena5|arena5tv|arena3|stadium|stadiumpro|*human> <sim seconds...>` — offscreen screenshots (Xvfb)
- `./shot.sh scene:res://scenes/menu.tscn 40 demo _show_league` — capture a UI screen
- `./export.sh [release|debug|emu]` — Android APK (release = arm64, signed; emu = x86_64 + GLES3 for the emulator)
- LAN smoke test: run `tools/lan_test.tscn -- host` and `-- client` headless

## Controls
Touch: floating joystick (left), PASS / SHOOT / THROUGH / SKILL / SPRINT (right; labels change with context:
TO ME! / RUN! when a teammate has the ball, TACKLE / SLIDE / CONTAIN when defending, THROW / KICK for keepers).
Desktop: WASD/arrows, J pass, K shoot (hold = power), L through, I skill, Shift sprint, C camera, Esc pause. Gamepad supported.
